Template card images
=====================

Drop images in THIS folder to replace the gradient thumbnails on the Templates page.
Each file name must match the card's key:

  job.jpg     -> Job Proposal
  web.jpg     -> Web design bid
  cover.jpg   -> Cover letter
  dev.jpg     -> Dev proposal
  mkt.jpg     -> Marketing bid
  gen.jpg     -> General

They are served automatically at /templates/<key>.jpg — no code change needed.
Recommended: landscape images, about 600x300px (2:1). .jpg or .png (keep the names above).
Until you add them, a colour gradient shows as a clean fallback.
